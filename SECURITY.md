# Security Policy

## Reporting a vulnerability

Do not disclose an unpatched vulnerability, credential, private endpoint, node address, user record, or exploit procedure in a public issue.

Use the official support channel linked from [singlinkvpn.com](https://singlinkvpn.com/) and clearly mark the report as a security disclosure. Include the affected version, platform, reproduction conditions, impact, and a safe contact method.

## Public disclosure

Security findings are published only after triage, remediation, release, and reasonable user update time. Public advisories distinguish confirmed impact from hypotheses and identify affected and fixed versions.

## Scope of this repository

The public tools in this repository validate research data and publication safety. Their presence does not imply that SingLinkVPN product source code or private infrastructure configuration is public.
