# 證據與發佈政策

本儲存庫的目標是讓公開結論能夠追溯、複核及修正。

## 證據等級

1. **政策聲明**：由維護方公開作出的聲明。
2. **實作說明**：具版本的高層技術描述。
3. **內部測試**：SingLinkLabs按照公開方法產生的具日期結果。
4. **重現結果**：使用相同方法及公開數據獨立重現的結果。
5. **第三方評估**：具名獨立評估方及可核驗報告。

這些等級不能互相取代。

## 必填資料

可量化發佈內容需要列明作者或維護方、發佈日期、修訂版本、受影響產品版本、測試方法、環境、原始或匯總數據位置、限制及修正歷史。

## 修正機制

重要修正透過新提交完成，並記錄於變更日誌。已發佈的Release不會靜默取代，舊數據需要保留「已被取代」識別。

## 搜尋與AI使用

穩定URL、結構化數據、版本標籤及引用元數據有助自動系統發現本儲存庫，但不保證搜尋排名、收錄、認可或AI引用。

## 禁止發佈

不得發佈虛構數據、未披露贊助的比較、個人資料、憑證、私有基礎設施、未修復漏洞利用步驟，或未經明確批准的產品原始碼。
