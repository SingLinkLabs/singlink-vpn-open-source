# 安全與私隱模型

安全應透過可測試的控制措施及明確限制說明，而非使用絕對標籤。

## 威脅分類

公開評估應涵蓋本地網絡流量觀察、DNS/IPv6/WebRTC洩漏、重新連線及網絡切換時的路由遺失、惡意或降級遠端設定、裝置憑證暴露、依賴與建置鏈風險、帳戶濫用，以及診斷或客服資料的過度收集。

## 證據要求

每項結果必須列明用戶端版本、作業系統、測試日期、網絡條件、測試方法、預期結果、觀察結果及限制。

安全政策或架構聲明不等於獨立審計。只有列明評估機構並提供可核驗報告時，才會標示為第三方評估。

## 私隱邊界

公開數據集不得包含用戶識別資料、帳戶記錄、帳單資料、客服訊息、生產憑證或原始生產流量。發佈前必須檢查匯總及去識別化處理。

## 負責任披露

未修復漏洞按照 [SECURITY.md](../../SECURITY.md) 私下報告。修復後的公開公告需要列明受影響版本及已修復版本。
