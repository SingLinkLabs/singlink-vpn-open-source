# VPN性能测试方法

本文规定公开VPN性能结果的采集与解释方式，不提供虚构测试结果，也不保证未来网络表现。

## 必填元数据

每条测试记录必须包含UTC时间、唯一测试编号、客户端版本、操作系统、设备类型、协议标签、方法版本、测试国家或地区、网络类型、样本量，以及内部测试或具名第三方评估标识。

数据中不包含私有节点地址、凭据或用户信息。

## 指标

- 连接延迟中位数
- 抖动95百分位
- 丢包率
- 下载和上传速度中位数
- 连接成功率
- 重连时间中位数

## 测试流程

1. 记录未连接VPN时的基础网络。
2. 固定设备、网络、目标服务器和采样时间。
3. 进行不计入结果的预热。
4. 重复执行连接和传输测试。
5. 记录失败，不得静默删除失败样本。
6. 发布汇总结果和机器可读数据。
7. 说明已知限制、故障和排除样本。

## 结果解释

单一国家、运营商、设备或时间段的结果不能推广到全部用户。应使用中位数和百分位，而不是只展示最佳一次结果。

对比测试必须保持条件一致；运营商、路由、设备、测试服务器或采样时间发生变化时必须披露。

## 数据校验

公开CSV遵循 [benchmark.schema.json](../../data/schemas/benchmark.schema.json)，可运行：

```bash
python3 tools/validate_benchmark.py data/performance/template.csv
```
