# VPN效能測試方法

本文規定公開VPN效能結果的收集及解釋方式，不提供虛構測試結果，亦不保證未來網絡表現。

## 必填元數據

每項測試記錄必須包含UTC時間、唯一測試編號、用戶端版本、作業系統、裝置類型、協議標籤、方法版本、測試國家或地區、網絡類型、樣本數，以及內部測試或具名第三方評估標示。

數據不包含私有節點地址、憑證或用戶資料。

## 指標

- 連線延遲中位數
- 抖動95百分位
- 封包遺失率
- 下載及上載速度中位數
- 連線成功率
- 重新連線時間中位數

## 測試流程

1. 記錄未連接VPN時的基礎網絡。
2. 固定裝置、網絡、目標伺服器及採樣時間。
3. 進行不計入結果的預熱。
4. 重複執行連線及傳輸測試。
5. 記錄失敗，不得靜默刪除失敗樣本。
6. 發佈匯總結果及機器可讀數據。
7. 說明已知限制、故障及排除樣本。

## 結果解釋

單一國家、營運商、裝置或時段的結果不能推廣至所有用戶。應使用中位數及百分位，而非只展示最佳一次結果。

比較測試必須保持條件一致；營運商、路由、裝置、測試伺服器或採樣時間改變時必須披露。
